4登录方式与安全

正式环境建议关掉短信登录和快捷登录卡

必须知道的安全边界：
这是纯前端网页，没有服务器校验。配置器会把密码做哈希后再写入， 源码里看不到明文，但任何懂技术的人仍可绕过。
它适合机构内部试用、试点验证； 涉及真实服务对象敏感信息、需要正式上线时，必须接入后端账号系统 （见下方「下一步」）。

5生成并下载

方案说明
接后端 API 把登录请求改成调用你们的服务器接口，密码校验在服务端做， 返回 token 后再进入首页。这是标准做法。
接机构统一认证 如果单位已有 OA / 政务统一身份认证，走 OAuth 或 CAS 对接， 社工用工号直接登录，不用另设密码。
接微信企业号 社工都在微信里，用企业微信扫码登录最省事， 也便于后续消息推送。
